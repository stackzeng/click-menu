| 项目 | 内容 |
|---|---|
| 产品名称 | ClickMenu |
| 平台 | macOS 13 Ventura 及以上 |
| 版本 | v1.0（MVP） |
| 文档状态 | 草稿 |
| 更新日期 | 2026-11-21 |

---

## 1. 背景与目标

### 1.1 背景
macOS 的 Finder 右键菜单功能有限，开发者和重度用户经常需要：
- 复制文件名（用于命名、搜索、写文档）
- 复制文件完整路径（用于终端、代码、配置文件）
- 在某个目录直接打开终端

系统自带方式繁琐：复制路径要按住 ⌥ 才出现「拷贝为路径名称」，打开终端要先开终端再 `cd`，复制文件名要进入重命名再全选复制。

### 1.2 产品目标
做一个轻量、原生、免费的 Finder 右键增强工具，把常用操作统一收进右键菜单中的 **「ClickMenu ▸」子菜单**，不占用右键菜单空间，展开即用。

### 1.3 目标用户
- 程序员、运维、设计师等经常和文件路径、终端打交道的 macOS 用户

### 1.4 成功标准
- 右键菜单中只新增一个「ClickMenu ▸」入口，三个核心功能在其子菜单中，点击后 ≤ 0.5 秒完成
- 安装到可用 ≤ 3 步（安装 → 打开 App → 启用扩展）
- 扩展常驻内存占用 < 30 MB

---

## 2. 产品形态

```
ClickMenu.app（宿主 App，菜单栏常驻）
├── 菜单栏图标：快速开关、打开设置、退出
├── 设置窗口：引导启用、菜单项配置、终端选择
└── ClickMenu Finder Extension（Finder Sync 扩展）
    └── 向 Finder 右键菜单注入菜单项
```

- 技术方案：Swift + SwiftUI + FinderSync 框架
- 扩展与宿主 App 通过 App Group 共享配置（`UserDefaults(suiteName:)`）
- 沙盒内无法完成的操作（如 AppleScript 控制 iTerm2）由扩展通知宿主 App 执行

## 3. 功能需求

### 3.1 核心功能（P0，v1.0 必须）

#### F0 统一入口（二级菜单）
| 项 | 说明 |
|---|---|
| 入口 | 右键菜单中只添加**一个**菜单项「ClickMenu ▸」，带 App 图标 |
| 展开 | 鼠标悬停展开子菜单，所有功能（F1~F3 及后续功能）都放在子菜单内，不在一级菜单单独出现 |
| 上下文 | 选中文件右键与空白处右键，子菜单内容不同（见 4.1） |
| 实现 | `FIFinderSync.menu(for:)` 返回一个父 `NSMenuItem`，其 `submenu` 挂载各功能项 |

#### F1 复制文件名
| 项 | 说明 |
|---|---|
| 触发 | 选中一个或多个文件 / 文件夹 → 右键 →「复制文件名」 |
| 结果 | 文件名（含扩展名）写入剪贴板 |
| 多选 | 每个文件名占一行，按 Finder 选中顺序 |
| 示例 | `/Users/bin/Desktop/报告 2026.pdf` → `报告 2026.pdf` |

#### F2 复制完整路径
| 项 | 说明 |
|---|---|
| 触发 | 选中一个或多个文件 / 文件夹 → 右键 →「复制完整路径」 |
| 结果 | 绝对路径写入剪贴板 |
| 多选 | 每个路径占一行 |
| 空白处 | 在 Finder 窗口空白处右键时，复制当前目录路径 |
| 示例 | `/Users/bin/Desktop/报告 2026.pdf` |

#### F3 在此处打开终端
| 项 | 说明 |
|---|---|
| 触发 | 选中文件 / 文件夹，或在窗口空白处 → 右键 →「在此处打开终端」 |
| 目录规则 | 选中文件夹 → 进入该文件夹；选中文件 → 进入文件所在目录；空白处 → 当前目录 |
| 默认终端 | 系统「终端」(Terminal.app) |
| 结果 | 打开一个新的终端窗口，工作目录为目标目录 |

#### F4 操作反馈
- 复制成功后在屏幕右上角显示轻提示 HUD：「已复制 1 个文件名」，1.5 秒后自动消失
- 可在设置里关闭提示

### 3.2 增强功能（P1，v1.1 计划）

| 编号 | 功能 | 说明 |
|---|---|---|
| F8 | 选择终端 | Terminal / iTerm2 / Warp / Ghostty / Alacritty |
| F10 | 菜单项自定义 | 勾选子菜单中显示哪些项、拖拽排序 |

> 已移除（v1.1.0）：F5 复制文件名（不含扩展名）、F6 复制转义路径、F7 复制 `~` 短路径、F9 用编辑器打开 —— 使用频率低，保持菜单精简。

### 3.2.1 自动更新（v1.1.0）

| 编号 | 功能 | 说明 |
|---|---|---|
| F12 | 后台检查更新 | 基于 Sparkle 2，每天检查一次 appcast（`appcast.xml`，托管在 GitHub 仓库 main 分支） |
| F13 | 新版本提示 | 后台发现新版本时不弹窗打扰：菜单栏图标出现红点，菜单顶部显示「⬆︎ 新版本 x.y.z 可用…」 |
| F14 | 一键安装 | 更新窗口显示版本号和更新说明，按钮：跳过此版本 / 稍后提醒 / 安装更新；下载后自动校验签名、替换并重启 |
| F15 | 手动检查 | 菜单栏「检查更新…」、设置 → 关于「检查更新」按钮，显示上次检查时间 |
| F16 | 更新设置 | 设置 → 关于：「自动检查更新」（默认开）、「自动下载并安装更新」（默认关） |
| F17 | 重启访达提示 | 更新后首次启动时提示「需要重启访达才能加载新版右键菜单」，按钮：稍后 / 重启访达 |

- 安全：更新包用 EdDSA 私钥签名（私钥只在开发者钥匙串中），App 内置公钥校验；DMG 同时经过 Developer ID 签名和 Apple 公证
- 1.0.0 没有更新功能，1.0.0 用户需手动下载 1.1.0 一次；之后版本都可一键更新
- 原型见「⑤ 自动更新」页面

### 3.3 远期功能（P2）
- 新建文件（txt / md / 自定义模板）
- 在当前目录执行自定义脚本
- 开机自启
- 中英文切换

## 4. 界面设计

> 交互原型见：`doc/prototype/index.html`（浏览器直接打开）

### 4.1 Finder 右键菜单
选中文件右键：
```
┌──────────────────────────┐
│ 打开                      │
│ 打开方式               ▸ │
│ ──────────────────────── │
│ ...                      │
│ ──────────────────────── │   ┌──────────────────────┐
│ ↖ ClickMenu            ▸ │──▶│ 📄 复制文件名        │
│ ──────────────────────── │   │ 📋 复制完整路径      │
│ 标签…                    │   │ 🖥 在此处打开终端    │
└──────────────────────────┘   └──────────────────────┘
```

空白处右键：
```
┌──────────────────────────┐
│ 新建文件夹               │
│ ...                      │   ┌──────────────────────┐
│ ↖ ClickMenu            ▸ │──▶│ 📋 复制当前目录路径  │
└──────────────────────────┘   │ 🖥 在此处打开终端    │
                               └──────────────────────┘
```
- 一级只有「ClickMenu ▸」一项；父菜单和子菜单项都带自绘单色图标（规范见 4.1.1）

#### 4.1.1 菜单图标规范

> 原型「① 右键菜单」页面底部有图标规范卡片，可看到 40px 放大图、常态和鼠标高亮时的效果。

| 规格 | 要求 |
|---|---|
| 画布 | 16×16 pt 彩色圆角方块（圆角 3.6pt，0.5pt 半透明描边），风格同「系统设置」侧边栏图标 |
| 底色 | 每个功能一种颜色，自上而下线性渐变（色值见下表） |
| 图形 | 白色线条图形，按 16 网格绘制后缩放到 66% 居中，实际线宽约 1.1pt，圆角端点与拐角 |
| 渲染 | 资源 *Render As: Original Image*（非模板），鼠标高亮时保持原色；深色模式下同样清晰 |
| 资源格式 | SVG 矢量放进 Assets.xcassets，勾选 *Preserve Vector Data*；单色图形源文件保存在 `ClickMenu/IconSources/` |
| 菜单栏图标 | 例外：菜单栏图标保持**单色模板**（`StatusBrand`），遵循 macOS 菜单栏规范，自动适配深浅色 |

| 菜单项 | 图标含义 | 底色 | 级别 | SF Symbols 备选 |
|---|---|---|---|---|
| ClickMenu（父菜单） | 鼠标箭头 + 点击光线（品牌标识，同菜单栏图标） | 蓝紫 #3D9BFF→#6B5CF0 | P0 | `cursorarrow.rays` |
| 复制文件名 | 文档 + 字母 T（名称） | 橙 #FFB340→#FF7A00 | P0 | `doc.text` |
| 复制完整路径 / 复制当前目录路径 | 文件夹 + 斜杠（路径分隔符） | 蓝 #4FC3FF→#0A7CFF | P0 | `folder` |
| 在此处打开终端 | 窗口 + 提示符 `>_` | 绿 #3EDC6E→#14A84A | P0 | `terminal` |

- 优先使用自绘图标（品牌一致、含义更准确）；自绘资源缺失时回退到 SF Symbols 备选（此时为单色）
- 右键菜单图标 `image.isTemplate = false`；菜单栏图标 `isTemplate = true`
- Finder 会把扩展菜单项放在固定位置，开发者不能控制具体插入点

### 4.2 菜单栏图标
点击后弹出：
- 状态：● 扩展已启用 /  ○ 扩展未启用（点击去启用）
- 设置…（⌘,）
- 关于 ClickMenu
- 退出（⌘Q）

### 4.3 设置窗口（4 个标签页）
1. **通用**：扩展启用状态与引导、开机自启、复制成功提示开关
2. **菜单**：子菜单中各功能项的开关与排序
3. **终端**：默认终端选择、打开方式（新窗口 / 新标签页）
4. **关于**：版本号、GitHub 链接、检查更新

### 4.4 首次启动引导
1. 欢迎页：介绍三个核心功能
2. 启用扩展：说明路径「系统设置 → 通用 → 登录项与扩展 → 访达」，提供「打开系统设置」按钮
3. 完成：自动检测到扩展启用后显示「一切就绪」，提示去 Finder 里右键试试

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 右键菜单弹出无可感知延迟；操作 ≤ 0.5 秒 |
| 兼容 | macOS 13+，Apple Silicon 与 Intel 都支持（Universal） |
| 隐私 | 只在检查更新时联网，不收集任何数据 |
| 安全 | 扩展运行在沙盒内；宿主 App 用 Developer ID 签名并公证 |
| 路径支持 | 中文、空格、emoji、特殊字符路径都正确；支持外接磁盘、iCloud Drive |

## 6. 边界情况

| 场景 | 处理方式 |
|---|---|
| 未选中任何文件且不在 Finder 窗口内（如桌面空白处） | 桌面按 `~/Desktop` 处理 |
| 选中项超过 100 个 | 正常复制，HUD 显示「已复制 N 项」 |
| 用户选择的终端未安装 | 回退到 Terminal.app，并提示去设置里修改 |
| 扩展被系统禁用 | 菜单栏图标显示警告状态，点击进入引导 |
| 网络卷 / 只读卷 | 复制功能正常；打开终端正常 |
